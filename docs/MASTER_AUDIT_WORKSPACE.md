# Master Audit Workspace v0.1.0 — architecture and review contract

## Scope

A single Qwen-selected `master_audit_workspace` branch hosts the pinned AuditGo binary installer, independent read-only repository memory, and an ordered, immutable-by-default audit stage queue. Go is the only validation/selection authority. A TypeScript module is an optional typed projection for future UI and a JS-facing queue; it cannot write records or execute targets.

### Inputs and provenance

- Historical Qwen `main` at `af6609fae097efe80742025b0b5bf27b9acfccea`: policy, recovery, original `kol_merkle` prompts and replay tools.
- Memory branch `feat/auditgo-curated-memory-v0.1.0` at `57a08f95db8f297136db6e2a5eed8730d0df6fc1`: pinned static catalog, pure Go memory reader and AuditGo archive.
- Gen Type-Go staging branch `feat/gen-type-go-pr6-deterministic-audit` at `f046b362a482d1fa4d557df284db3cf39bf0a55d`: exact pinned lock `901c8cf5f4636351ae228ef351b61d97a0d4589b` (Git blob) and replay script `7b225092a877f33f1e582969c9988f13c3687a99` (Git blob).

These values are **historical frozen source identities**, not live attestation of current target state. Do not auto-update them.

### Startup state machine

```text
QWEN_REPO_SELECTED
    -> SHELL_PREFLIGHT
    -> OVERLAY_SHA_VERIFIED
    -> AUDITGO_PINNED_INSTALL_AND_DOCTOR
    -> AUDITGO_PLANNING_SMOKE
    -> REPO_MEMORY_READ_ONLY_VERIFY
    -> GO_STAGE_QUEUE_VERIFY
    -> MASTER_AUDIT_WORKSPACE_READY
    -> [OPTIONAL explicit stage-audit.sh]
    -> STAGED_NOT_EXECUTED
    -> [SEPARATE owner authorization + isolated target replay]
    -> EVIDENCE_COLLECTION / SOURCE AUDIT
    -> INDEPENDENT REVIEW / OWNER DECISION
```

No startup transition crosses into target execution. A lock mismatch, invalid JSON, escaping-equivalent duplicate key, missing file, changed protected hash, symlink, unknown stage or forged authorization fails closed.

### Immutable memory and queue

Memory is repository-curated, not generated by Qwen. The Go reader supports `verify`, `doctor`, `list`, `context`, and `get`; no save. The queue reader supports only `verify`, `list`, and `context`, and treats all prior context as data. `audit-artifacts/` is local run output (ignored by Git), not long-term memory. A compromised actor with broad repository write access could modify both a JSON file and its checksum; only CODEOWNERS and branch rules can enforce stronger protections.

### Pinned targets

`gen-type-go-pr6` is staged; historical `kol-merkle-pr4` is reference-only and cannot be staged without an owner-reviewed queue/lock update. The Gen Type-Go replay maintains its own isolated clone and tests; it is **not** called during bootstrap or stage preparation.

### Go + TypeScript division

`tools/masteraudit/main.go` strictly verifies the source-of-truth JSON and referenced files, materializes a read-only context to stdout, and has no write or network operations. `tools/masteraudit/queue.ts` describes the context shape and produces an immutable display record. Only use TS after successful Go validation. Runtime Node/TypeScript is optional; Qwen only needs Go + shell.

### Test commands

```sh
sha256sum -c OVERLAY_SHA256SUMS.txt
sh scripts/setup-master-audit-workspace.sh
go test -count=1 ./tools/masteraudit/main.go ./tools/masteraudit/main_test.go
go test -race -count=1 ./tools/masteraudit/main.go ./tools/masteraudit/main_test.go
go vet ./tools/masteraudit/main.go ./tools/masteraudit/main_test.go
node --experimental-strip-types --test tools/masteraudit/queue.test.mjs  # optional Node >= 22
sh scripts/stage-audit.sh gen-type-go-pr6
```

The `OVERLAY_SHA256SUMS.txt` index covers all overlay-added or replaced files; original `main` assets (e.g. `AUDIT_POLICY.md`) must match the preserved main Git blobs. A CI smoke that only runs `init`/`plan` is not a completed audit. The finished audit must return its actual evidence ledger, evidence-classified findings, short human summary and checksum-identified receipt. No repo or target changes, PR comments, approval, merge or release without separate authority.
